Welcome to the TensorWorld blog. We will use this space to share research notes,
tutorials, and updates from the group.

To add a new post, create a Markdown file under `_posts/` named
`YYYY-MM-DD-title.md` with front matter (`title`, `date`, `author`, `description`),
then write the post body in Markdown below it.
